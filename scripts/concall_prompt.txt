[MANDATORY CELL FORMAT — applies to EVERY growth-guidance column in Table_A]
Each populated cell MUST declare what kind of number it is. Use exactly one of the
three forms below. NEVER write a bare number.

1. GROWTH RATE — a percentage CHANGE. This is the default for these columns.
   Write with an explicit % sign:      15%        15-20%        -8%
   Keep a range as a range; do NOT pre-average it.

2. ABSOLUTE TARGET — a level, not a change (rupee target, physical capacity, unit
   count). Prefix with "ABS:" and ALWAYS state the unit:
        ABS: INR 530 cr        ABS: 178000 MT        ABS: 60000 sites
   NEVER place a bare absolute number in a growth column.

3. LEVEL PERCENTAGE — a % that is a STATE, not a change (utilisation, margin,
   occupancy, market share). Prefix with "LVL:":
        LVL: 75% (utilisation)         LVL: 23.5% (EBITDA margin)
   A margin or utilisation figure is a LEVEL, never a growth rate.

CAPACITY is the most-confused metric — decide explicitly which of the three it is:
   - "capacity will rise from 125,000 to 147,000 tons"  ->  ABS: 147000 MT
   - "we expect to reach 75% utilisation"               ->  LVL: 75% (utilisation)
   - "we will add 40% more capacity"                    ->  40%
If the transcript does not make it clear, write NA rather than guessing.

CONVERTING an absolute target into a growth rate is allowed ONLY when the
transcript also states the base. Then show both:
        25% (derived: 400 -> 500 cr)
If the base is absent, use ABS: and leave the growth cell NA.
